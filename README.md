# Concessionária AutoMobi

## Sistema de controle de veículos

Um sistema robusto e completo que gerencia veículos em uma concessionária.

## Funcionalidades

### Cadastro

Realizar o cadastro de veiculos, usando dados como Modelo, Cor, km, Ano e Marca, o sistema vai validar os dados. 

### Atualização

Atualizar os dados de um veículo já existente na base de dados, antes de alterar, o sistema valida os dados, a função valida se o veiculo existe antes de tentar remover. 

### Leitura

Listar todos os veículos da base de dados, formatando em uma lista para melhor visualização.
